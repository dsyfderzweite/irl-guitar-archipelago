# IRL Guitar Archipelago
Implementation of a client that turns playing the guitar into an Archipelago game.

Archipelago is a multiworld multi-game randomizer. More information can be found on the [official website](https://archipelago.gg/).

## Milestones

The project is currently in early development. Significant updates will be posted here.

## Concept

### Client

The client is written in C#/.NET 10.0 using the framework MonoGame.

### World

The Items consist of the eight fingers used to play the guitar as well as the six strings. Locations are made up of a selection of the 24 Exercises Op. 35 by Fernando Sor with additional early game locations taken from his book "Method for the Guitar".
